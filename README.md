# 🌍 EcoCity Builder

> **Can you design the ultimate sustainable metropolis before time runs out?**

**EcoCity Builder** is a lightweight, strategic 5×5 grid simulation game built purely in Vanilla HTML, CSS, and JavaScript. Players manage a starting budget to balance clean energy, residential zones, and nature reserves while keeping pollution low and citizen happiness high.

### ✨ Key Features
- ⏱️ **Timer-on-First-Move:** 3-minute countdown starts only when you place your first building.
- 🔄 **Dynamic Undo / Refund:** Click any occupied tile to remove buildings and refund your budget on the fly.
- 🌿 **Eco-Diversity Scoring:** Strategic scoring engine that rewards balanced city blueprints (clean energy, housing, nature, and resources) with up to **+75 harmony bonus points**.
- 🛑 **Early Stop Mechanic:** Lock in your city and submit your score whenever your layout is perfected.
- 🏆 **Zero-Backend Leaderboard:** Persistent Hall of Fame that syncs directly with local storage and desktop `leaderboard.json` using the modern File System Access API — completely playable offline or straight from a double-click!
